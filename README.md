## Проекты в репизитории:

### 1. SimpleCalculator.java
**Простой консольный калькулятор** - Моя первая валидная Java программа!
- выполняет 5 операций (+,-,*,%,/)
- использует целые и дробные числа
- запускается из командой строки
  
### 2. FirstScanner.java
**Простой ввод от пользователя** - Моя валидная Java программа!
- просит ввести имя и возраст
- запускается не из командой строки!

### 3. WhoareYou.java
**Скажет кто ты по уровню в какой-либо игре** - Моя валидная Java программа!
- Просит ввести свой игровой уровень
- Покажет кто ты
- Запускается не из командной строки!

### 4. AmmuNationShop.java
**Залетай в магазин оружия и приобрети свой ган!** - Моя валидная Java программа!
- Выводит твой баланс
- Просит выбрать что купить
- Выводит остаток
- При нулевом балансе сообщает об этом
- Запускается не из командной строки!
