## Проекты в репизитории:
### 1. SimpleCalculator.java
**Простой консольный калькулятор** - Моя первая рабочая Java программа!
- выполняет 5 операций (+,-,*,%,/)
- использует целые и дробные числа
- запускается из командой строки

**Как запустить:**

javac SimpleCalculator.java

java SimpleCalculator
### 2. FirstScanner.java
**Простой ввод от пользователя** - Моя вторая рабочая Java программа!
- просит ввести имя и возраст
- запускается не из командой строки!

### 3. WhoareYou.java
**Скажет кто ты по уровню в какой-либо игре** - Моя третья рабочая Java программа!
- Просит ввести свой игровой уровень
- Покажет кто ты
- Запускается не из командной строки!
